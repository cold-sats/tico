# New hire onboarding

## Day one

The new hire gets a laptop and accounts for email, the chat tool and the project tracker. The manager assigns
a buddy from the same team.

## First week

- Complete the security training. It takes about an hour and must be done before access to customer data.
- Read the product tour and the support handbook.
- Meet the founder for thirty minutes.

## First month

A 30-60-90 plan is agreed with the manager in week two and reviewed at the end of each period.
