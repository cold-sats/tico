# Team docs sync (moved)

The repository mirror this page described (a worker importing linked repositories, the "Current docs" view, Bot Notes,
Proposed changes, and Doc Updater's link-repository setting) is gone. Team docs are now written, pasted or imported
in Tico as internal docs, or linked from where they live: see [docs.md](docs.md). Linked sources and approved
documentation repositories from the old mirror were carried over as linked docs the first time the new version started.
