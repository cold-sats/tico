# Building overview

Overview is the first navigation item on desktop and in the mobile bar and drawer. Updates remains the default page. A group becomes a floor; selecting it opens a cutaway office. Select a teammate to see their reported status and open their existing profile or bot page.

The scene uses the existing `/employees`, `/humans` and `/v2/status` responses and refresh loop. It creates no new server endpoint or background poll. Group membership, display names and bot status come from the signed-in person's roster. Hidden people, invisible or retired bots and other people's personal branches are excluded. Read-restricted bots have no activity details. Free-text task focus is never sent to the renderer. Human presence is not tracked. If refresh fails, bots become unknown and stop their activity animation.

Ungrouped teammates appear in Shared space; built-in and message helper bots appear in Team services. Every group is a floor. The distant building shows up to six representatives per floor; entering an office reveals all of its teammates without pagination. Department names are backlit signs on each room’s rear wall. The scene stays in night mode, with no dropdown, toolbars, or persistent labels. Tap a floor to enter and tap outside the room (or press Escape) to return. Keyboard-accessible department and teammate buttons appear only when focused. Empty groups remain visible. Rooms and scenery are decorative, not a physical seating plan, traffic history or measure of productivity.

`ui/app/overview.js` supplies this minimal model to a lazy same-origin iframe in `ui/overview/`. Both sides check message origin and source. Profile requests are checked against the current roster before navigating. The iframe, event listeners and GPU resources are disposed when leaving the route. Membership changes rebuild the scene; status-only refreshes preserve the camera and selected teammate. No Three.js assets load on the default page.

The isolated renderer uses native ES modules and locally vendored Three.js; it needs no build step or external CDN. `ui/vendor/three/` contains Three.js 0.186.1, RoundedBoxGeometry and BufferGeometryUtils, with its MIT license. Import paths point at sibling vendored modules. Geometry and materials are shared and static scenery is batched. Device pixel ratio is capped, invisible documents stop rendering and reduced-motion preferences pause decorative motion. If WebGL is unavailable, the same authorized roster remains accessible as a list.

Run `node scripts/ui-tests.cjs overview updates` with Playwright installed. The overview test covers the bundled app, permission filtering, escaped names, status failure/recovery, scene navigation, mobile fit, route cleanup, WebGL fallback and an empty company. Run `python -m backend.demo --port 18766` for visual review at `http://localhost:18766/#/overview`; the local demo explicitly uses fictional sample data.
