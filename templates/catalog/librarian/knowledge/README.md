# knowledge

The map of the company's docs is not kept here: it is kept in Tico, as internal docs under
`_librarian/`, where people can read and correct it (`playbooks/the-map.md`). This directory holds only
what you learned about *reading* this company's docs that would still help a fresh session: which
linked source is the authority on what, which site needs its sitemap walked rather than searched, a
page that looks current but is stale. One topic per file, dated, no secrets.
